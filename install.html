Installation Guide

Step 1: Download APK

Click the Download button on the homepage to save the APK to your phone.

Step 2: Allow Unknown Sources

Huawei / Honor

Settings → Security → More Security Settings → External Source App Check → Select Browser/File Manager → Allow

Xiaomi / Redmi

Settings → Privacy Protection → Special Permissions → Install Unknown Apps → Select Browser/File Manager → Allow

OPPO / vivo

Settings → Security → Install Unknown Apps → Select Browser/File Manager → Allow

Samsung

Settings → Biometrics and Security → Install Unknown Apps → Select Browser/File Manager → Allow

Step 3: Install

Open File Manager → Downloads → Tap the OKX APK → Tap Install → Wait

Step 4: Launch

Find OKX icon on your home screen and open.

Troubleshooting

"Parse Error"

APK download incomplete. Re-download. Requires Android 7.0+.

"App Not Installed"

Uninstall old version first.
