Installation Guide

Step 1: Download APK

Click Download on the homepage to save the APK.

Step 2: Allow Unknown Sources

Huawei / Honor

Settings > Security > More Security > External Source App Check > Allow

Xiaomi / Redmi

Settings > Privacy > Special Permissions > Install Unknown Apps > Allow

OPPO / vivo

Settings > Security > Install Unknown Apps > Allow

Samsung

Settings > Biometrics and Security > Install Unknown Apps > Allow

Step 3: Install

File Manager > Downloads > Tap APK > Install > Wait

Step 4: Launch

Find OKX icon on home screen and open.

Troubleshooting

Parse Error

APK incomplete. Re-download. Needs Android 7.0+.

App Not Installed

Uninstall old version first.
