OKX APK 安装教程

第一步：下载 APK 文件

点击首页的 「立即下载」 按钮，将 APK 文件保存到手机。

第二步：允许安装未知来源应用

不同手机品牌设置位置略有不同：

华为 / 荣耀

设置 → 安全 → 更多安全设置 → 外部来源应用检查 → 选择浏览器/文件管理器 → 允许

小米 / Redmi

设置 → 隐私保护 → 特殊权限 → 安装未知应用 → 选择浏览器/文件管理器 → 允许

OPPO / vivo

设置 → 安全 → 安装未知应用 → 选择浏览器/文件管理器 → 允许

三星

设置 → 生物识别和安全性 → 安装未知应用 → 选择浏览器/文件管理器 → 允许

第三步：安装 APK

打开手机的「文件管理器」→ 找到「下载(Download)」文件夹 → 点击 OKX APK 文件 → 点击「安装」→ 等待完成

第四步：打开应用

安装完成后，在桌面找到 OKX 图标，点击打开。首次启动可能需要加载资源，请耐心等待。

常见安装问题

安装时提示「解析错误」

APK 文件下载不完整，请重新下载。或检查手机系统是否为 Android 7.0 以上。

安装时提示「应用未安装」

手机可能已安装旧版本 OKX，请先卸载旧版再安装新版。

点击 APK 没反应

确认已允许文件管理器安装未知来源应用的权限（见第二步）。
